# 🎨 Как подключить CSS к HTML

Есть **3 основных способа** подключения CSS.  
Для обучения и реальных проектов важно понимать **каждый**.

---

## 🥇 Способ 1. Внешний CSS-файл (**рекомендуется**)

### 📁 Структура файлов
```diff
index.html
styles.css
```

📄 `index.html`
```html
<!DOCTYPE html>
<html>
<head>
  <title>Моя страница</title>
  <link rel="stylesheet" href="styles.css">
</head>
<body>

  <h1>Привет, QA!</h1>

</body>
</html>
```
🎨 `styles.css`
```css
h1 {
  color: blue;
  text-align: center;
}
```
### ✅ Плюсы
- Чистый HTML
- Легко поддерживать
- Так делают в реальных проектах

## 🥈 Способ 2. CSS внутри HTML (`<style>`)
```html
<head>
  <style>
    h1 {
      color: green;
    }
  </style>
</head>
```
### Когда используется
- Быстрые прототипы
- Учебные примеры
- Маленькие страницы

## 🥉 Способ 3. Inline CSS (прямо в теге)
```html
<h1 style="color: red;">Привет!</h1>
```
### ⚠️ Минусы
- Плохо поддерживается
- Сложно тестировать
- Часто причина багов

---
### 📘 Теория
- Что такое CSS
- Inline vs `<style>` vs отдельный файл
- Селекторы

### 🧪 Практика
Добавляем базовый стиль:
```css
<style>
  body {
    font-family: Arial;
    background-color: #f5f5f5;
  }

  h1 {
    color: #333;
  }
</style>
```
### 🧠 QA-фокус
- Проверка отображения
- Проверка консистентности UI
- Работа со Styles в DevTools

```css
.card {
  background: white;
  padding: 16px;
  border-radius: 8px;
}
```

## 📦 Простая адаптивность

### 📘 Теория

- Что такое responsive
- Почему важно для QA
- Mobile vs Desktop

### 🧪 Практика
Добавляем адаптивность:
```css
@media (max-width: 600px) {
  .card {
    font-size: 14px;
  }
}
```
### 🧠 QA-фокус
- Проверка через DevTools → Responsive mode
- Проверка мобильной версии
