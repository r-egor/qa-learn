### 📘 Теория
- Что такое CSS
- Inline vs `<style>` vs отдельный файл
- Селекторы

### 🧪 Практика
Добавляем базовый стиль:
```css
<style>
  body {
    font-family: Arial;
    background-color: #f5f5f5;
  }

  h1 {
    color: #333;
  }
</style>
```
### 🧠 QA-фокус
- Проверка отображения
- Проверка консистентности UI
- Работа со Styles в DevTools

```css
.card {
  background: white;

  border-radius: 8px;
}
```

## 📦 Простая адаптивность

### 📘 Теория

- Что такое responsive
- Почему важно для QA
- Mobile vs Desktop

### 🧪 Практика
Добавляем адаптивность:
```css
@media (max-width: 600px) {
  .card {
    font-size: 14px;
  }
}
```
### 🧠 QA-фокус
- Проверка через DevTools → Responsive mode
- Проверка мобильной версии
