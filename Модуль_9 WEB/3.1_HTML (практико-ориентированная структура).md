## 🎯 Цель модуля

Понять, **из чего состоит веб-страница**, научиться **читать HTML/CSS глазами QA**, и **постепенно собрать красивую HTML-страницу**, не углубляясь в разработку.

---

## 📦 Базовая HTML-структура страницы

### 📘 Теория
- Что такое HTML
- Что такое теги
- Что такое вложенность
- Что такое `<head>` и `<body>`
### 🧪 Практика

Создаём **каркас страницы**:
```html
<!DOCTYPE html>
<html>
<head>
  <title>Моя первая страница</title>
</head>
<body>

</body>
</html>
```
### 🧠 QA-фокус
- Проверить, что страница открывается
- Понять, где появляется контент
- Открыть DevTools → Elements
---
## 📦 Текст, заголовки 

### 📘 Теория
- Заголовки `<h1>–<h6>`
- Текст `<p>`
- Семантика: зачем это QA

### 🧪 Практика
Добавляем контент:
```html
<h1>Профиль пользователя</h1>
<p>Добро пожаловать в тестовое приложение</p>
```
### 🧠 QA-фокус
- Проверка структуры страницы
- Проверка иерархии заголовков
---
## 📦 Кнопки, ссылки и поля ввода
### 📘 Теория
- `<button>`
- `<a>`
- `<input>`
- placeholder / type

### 🧪 Практика
Добавляем интерактивные элементы:
```html
<input type="text" placeholder="Введите имя">
<button>Сохранить</button>
<a href="#">Перейти в профиль</a>
```
### 🧠 QA-фокус
- Hit-area кнопок
- Проверка кликабельности
- Проверка placeholder
- Основы UI-тестов
---
## 📦 Блоки и верстка
### 📘 Теория
- `<div>`
- Контейнеры
- Отступы и границы
### 🧪 Практика
Делаем карточку:
```html
<div class="card">
  <h2>Иван Иванов</h2>
  <p>Email: test@example.com</p>
</div>
```

## 📦 Мини-интерактив (JS минимум)
### 📘 Теория
- Зачем QA понимать JS
- Event, click

### 🧪 Практика
Добавляем реакцию:
```js
<button onclick="alert('Сохранено!')">Сохранить</button>
```
### 🧠 QA-фокус
- Проверка событий
- Проверка ошибок в Console 
- Подготовка к E2E тестам
